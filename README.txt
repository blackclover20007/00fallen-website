00FALLEN website
=================

Files:
- index.html: responsive dark portfolio website
- assets/fallen-portrait.png: your uploaded portrait
- assets/i-am-fallen-cover.png: your uploaded cover artwork

Preview:
Open index.html in a browser. Keep the assets folder next to index.html.

Publishing:
Upload index.html and the assets folder to a static website host such as GitHub Pages, Netlify, or your preferred hosting provider.
