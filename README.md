# 00FALLEN — Official Website

A responsive, single-page personal site for 00FALLEN: music, hoops, streetwear, and late-night energy.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8080
```

## Deploy

This is a zero-build static site. It is configured for Vercel and can also be hosted on GitHub Pages, Netlify, or any static host. The `assets/` folder must remain next to `index.html`.
